# Grouped self import identities

These six original public synthetic cases use MIT OR Apache-2.0. In a grouped
use tree, terminal self names the preceding namespace. It does not add another
module. The existing root-alias policy therefore rejects std/core root aliases
expressed through grouped self, including raw roots and application effects.
Selected pure fmt and inward domain namespaces remain permitted. Independent
expected review precedes consumption; prior204case bytes remain unchanged.
These are syntax-policy inputs and do not claim actual runtime qualification.
