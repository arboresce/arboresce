# Explicit source and observation regressions

This original public synthetic package uses MIT OR Apache-2.0. It adds source,
Cargo inventory and actual native-observation discriminators to the immutable
96-case guard-v1 package. Independent expected acceptance precedes consumption.
Expected decisions follow the architecture and testing requirements; they are
not sampled from an implementation. Rust snippets are policy syntax inputs,
not compiled product or live SDK evidence.

Panic-producing UFCS methods, imported panic aliases/functions and raw identifiers
have the same policy as their direct spellings. Safe Option defaults and pure
marker/value imports remain allowed. Platform filesystem/network/descriptor
surfaces belong to effectful boundaries; selected ffi/raw value imports remain
pure. Literal text inside a formatting macro remains data.

The closed initial source profile rejects explicit path attributes and include!
until a first consumer qualifies their complete sources. Ordinary modules under
src remain guarded recursively. include_str! and include_bytes! provide data,
not source-code inclusion. Cargo library/bin/build targets must reconcile to their
owning src root. The exact registered test-peer binary is separately owned and
measured, with no production exemption for another path or package.

Native probes use the actual built tool and preclosed standard pipes. Observer
budget cases use pre-existing absolute operating-system utilities, whose bytes
and identity are retained in private qualification evidence. They are not Rust
product stand-ins. Observation and bounded output collection must finish before
the budget. The late-observation case explicitly delays the first observation
by 50 ms against a 10 ms budget; every other case has zero initial delay. Late
observation cannot admit an already-exited child. Cleanup is
limited to the child and fresh task-owned files. An external killed sleep is
not required to emit a Rust profile; every maintained Rust child still is.

Full LLVM source/object/profile collection, ordinary public-checkout use and
whole verification qualification remain separate mandatory gates.
