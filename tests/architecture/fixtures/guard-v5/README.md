These five original public synthetic cases use MIT OR Apache-2.0. They qualify
maintained support failure paths required by the complete testing contract.
Independent expected review precedes consumption. Existing 199 cases remain
unchanged, with no source exemption or percentage adjustment.

The existing actual test-peer metadata mode emits exact prepared bytes. An
8 MiB plus one-byte payload must fail the collector's selected 8 MiB bound with
InvalidData. The child itself exits zero; collection failure cannot become an
accepted outcome, and its nonempty fresh Rust profile still must be conserved.
The payload is an explicit original byte recipe with a declared digest, not a
model response or customer file.

The four filesystem cases are actual conflicts inside exclusive task-owned
namespaces. Preparation must propagate the stated native-profile I/O error; it
cannot pretend missing fixture data or a failed peer registration succeeded.
The duplicate registration preserves the existing symlink. Cleanup remains
limited to the fresh namespace; these tests do not qualify product storage.
