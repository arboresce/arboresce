# Native launch publication boundaries

These independently authored expectations precede their consumers. The owning
[native collection contract](../../../../docs/requirements/testing-and-coverage.md)
defines the selected local publication frame, unchanged identity checks, 64 KiB
inclusive limit and fixed earlier-of deadline. A final LF is readiness only.
The literal positive and negative answers were authored from that contract,
not copied from verifier output.

The 37 cases cover the ordinary no-op path and explicit descriptor observation;
delayed absent/empty/partial publication and final-LF completion; permanently
missing/empty/partial/unframed inputs; completed malformed, conflicting and
non-UTF-8 records; strict single-value parsing; context mutation; deterministic
selected-path replacement, unlink, symlink and directory transitions; initial
symlink/directory/FIFO refusal; exact 64 KiB and one byte over; original and
maximum publication deadlines; and observer failure/elapsed work.

Every native case uses the real built test peer and parent-created receipt for
that actual Child. Preserve those original bytes separately. Controlled owned
mutations are explicit inputs, not fabricated launches, statuses or historical
race evidence. The optional selection acknowledgement is emitted only after
the real descriptor is selected, before its controlled parent mutation. It
carries no admission authority. Complete native streams, trace, actual status,
context/environment conservation and actual main raw profile remain required.
After the child completes, restore only the owned context/receipt as needed for
its genuine local completion, retaining the original and mutated bytes and
physical evidence. A later correct frame cannot repair an earlier refusal.

The selected receipt reader admits only the exact fields validated by the
existing outer identity gate; this package adds no API data field, feature,
dependency, platform, filter, retry, exemption, suite timeout or coverage floor.
Existing actual record-create/write/flush failure and bounded owned cleanup
cases remain mandatory. New native boundary success cannot replace complete
unfiltered owning/public qualification or independent source/delivery review.
