# Standard source-inclusion aliases

These seven original public synthetic cases use MIT OR Apache-2.0. The existing
unselected include! source boundary applies equally to std/core imports, renamed
imports, groups and raw identifiers. Otherwise a standard include alias could
compile source outside the guarded inventory. Text/byte resource aliases remain
data and retain their positive policy. Independent expected acceptance precedes
consumption; these snippets do not establish compiled product/runtime behavior.
All earlier independently accepted literals are preserved unchanged.
